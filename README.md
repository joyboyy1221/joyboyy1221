## Web3 projects

**[BaseCraft](https://github.com/joyboyy1221/basecraft)**, live on Base Mainnet.
A daily GM streak dapp with a Minecraft theme, leaderboards and achievement badges.
Contract: [`0x73D20F5...664A002`](https://basescan.org/address/0x73D20F5419f4edB3eb1731C4C66C6045D664A002)

**[PantaWire](https://github.com/joyboyy1221/pantawire)**, built for the Panta API hackathon.
Minecraft themed prediction markets on Solana. Mine blocks to discover markets, craft new predictions and trade with USDC.

**[SolFlow](https://github.com/joyboyy1221/solflow)**, [live app](https://solflow-gamma.vercel.app).
Real time Solana money flow visualizer powered by Solami infrastructure.

**[Pixel Chest](https://github.com/joyboyy1221/pixel-chest)**
Decentralized file storage with a pixel art interface on Aptos, built on Shelby Protocol.

**[Shelby File Manager](https://github.com/joyboyy1221/shelby-file-manager)**
File manager frontend for Shelby Protocol, built with React and Vite.

**[AutoGig](https://github.com/joyboyy1221/autogig)**
Next.js dapp built with wagmi, viem and RainbowKit.

**[FhenixVote](https://github.com/joyboyy1221/fhenixvote)**
Voting app built with Next.js for the Fhenix ecosystem.
